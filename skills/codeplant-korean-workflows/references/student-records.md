# 학생 기록 작성

## 증거 중심 구조

학생이 실제로 보인 다음 흐름만 사용한다.

1. 어떤 문제나 궁금증을 발견했는가
2. 어떤 질문을 만들었는가
3. 무엇을 조사·설계·제작·수정했는가
4. 교사가 확인할 수 있는 변화나 결과가 무엇인가

## 금지 사항

- 입력 자료에 없는 개인별 역할, 리더십, 수상, 성취, 진로 확신을 만들지 않는다.
- 조별 결과를 특정 학생 개인의 성과로 바꾸지 않는다.
- 모든 학생에게 같은 첫 문장이나 같은 성장 서사를 반복하지 않는다.
- 단순 참여를 주도, 탁월, 심화 탐구로 과장하지 않는다.

## 표현 원칙

- 교사 관찰 문체를 사용한다.
- 활동명 나열보다 학생의 질문, 선택, 수정 과정을 중심에 둔다.
- 기술 용어는 학생이 실제 사용한 범위에서만 쓴다.
- 자료가 부족하면 평가 문장을 늘리지 말고 `[개별 관찰 근거 확인 필요]`로 남긴다.

완성 후 학생별 고유 근거, 중복 문장, 금지 표현, 글자 수를 검사한다.
