# GEO Desk 역할별 검수

## 검수 범위

기존 GEO Desk를 UX/UI 디자이너, 프로그램 개발자, 최종 검수자 세 역할로 나누어 검토했다. 초기 감사 → 담당별 수정 → 통합 테스트와 브라우저 확인 → 최종 독립 검수 순서로 진행한다.

## UX/UI 디자이너

관리자 로그인과 키 등록, 설정 저장·연결 확인, 질문 처리 중 상태, 대화 전환·삭제, 실패 시 초안 복구, 키보드 조작, 좁은 화면의 가독성을 검토한다. 기존 녹색·회색 디자인과 외부 패키지 없는 실행 방식을 유지한다.

## 프로그램 개발자

관리자 인증과 세션, Origin 검사, DPAPI 저장, 설정 검증, API 연결 오류, 같은 대화의 동시 요청, 처리 중 삭제, 실행·종료 스크립트의 프로세스 식별, 격리된 테스트를 검토한다.

## 최종 검수자

수정 담당자와 별도로 소스·테스트 결과·실제 브라우저 캡처를 확인한다. 초기 발견 사항이 해결됐는지와 새로운 회귀가 있는지 확인하고, 검증한 범위와 남은 제한을 구분한다.

## 초기 발견 사항

- 질문 처리 중 대화를 삭제하면 화면과 저장 상태가 충돌할 수 있었다.
- 모델 변경 후 이전 모델의 연결 확인 성공 표시가 남을 수 있었다.
- 일부 전송 오류에서 1차 답변의 저장과 2차 분석 실패 처리가 구분되지 않았다.
- 관리자 초기 비밀번호 안내가 공개 프로그램 폴더 구조와 달랐다.

위 문제와 추가 발견한 인용 위치의 앞쪽 공백 오류를 수정했다. 같은 대화의 동시 요청과 삭제는 서버에서도 차단하고, 모델이 바뀌면 이전 연결 확인 상태를 초기화한다. 2차 분석 실패 시 이미 생성된 1차 답변을 유지한다.

## 통합 확인과 판정

- 모의 API를 이용한 HTTP·단위 회귀 테스트 10개 통과. 실제 OpenAI를 호출하지 않는 격리된 테스트다.
- 실제 브라우저에서 키 미등록 상태, 관리자 로그인·저장·연결 확인, 작업 중 버튼 잠금, 답변·출처·GEO 지표, 실패 시 초안과 버튼 복구를 확인했다. 응답 내용은 명시적으로 검수용 가짜 자료를 사용했다.
- 데스크톱 1280px·모바일 390px 캡처를 최종 검수자가 독립 확인했다. 모바일 화면에서 가로 넘침이 없었다.
- 실행 완료 확인, 같은 서버 재실행, 해당 앱 프로세스만 종료, 이미 종료한 상태에서 다시 종료하는 동작을 확인했다.
- 운영본에서도 종료·실행·반복 실행·재종료·재실행을 확인했다. 기존 키·관리자 로그인·설정·대화가 백업과 동일하게 유지되는지 확인했다.
- 바탕화면 실행·종료 바로가기를 설치하고 대상 경로를 확인했다. 실행 바로가기로 페이지를 여는 경로도 실행했다. 종료 확인창의 실제 사용자 클릭은 자동화하지 않았다.

최종 검수자는 **통합 소스와 가짜 API 기반 검수 통과, 배포를 막는 미해결 결함 없음**으로 판정했다. 운영본은 저장 데이터를 보존해 갱신했다.

이번 역할별 검수에서는 유료 OpenAI 호출을 추가하지 않았다. 다른 내부망 기기에서의 접속, 파일 내보내기 다운로드, 실제 비밀번호 변경 확인 입력의 브라우저 동작, 대비와 축소 동작의 모든 조합은 검증 범위에 포함되지 않는다. 초기 실제 API 연결 확인 결과와 모의 UI 검수 결과를 구분한다.
